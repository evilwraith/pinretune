# PSAperio - Utility library
PSAperio is a library that enables encryption[^Crypt], decryption[^Crypt], scrambling and unscrambling of PinSound[^PinSound] configuration files and sound packs.


[^Crypt]: Due to laws on circumvention of copy protection there are no encryption keys included with this project. The keys need to be extracted from a live version of PinSound Studio Pro.
